# ภัทราวุธมาณพปุจฉา (Bhadrāvudha Manava Puccha) 🪷

> **ปุจฉาที่ ๑๒ จาก โสฬสปัญหา ปารายนวรรค สุตตนิบาต ขุททกนิกาย พระสุตตันตปิฎก**

โปรเจกต์นี้นำเสนอเนื้อหาและธรรมวิจารณ์ของ **ภัทราวุธมาณพปุจฉา** หนึ่งใน ๑๖ คำถาม (โสฬสปัญหา) คำถามนี้มีความพิเศษตรงที่มาณพได้ทูลขอให้พระผู้มีพระภาคเจ้าแสดงธรรมแก่หมู่ชนจำนวนมากที่หลั่งไหลมาฟังธรรม เป็นการแสดงให้เห็นถึงพระมหากรุณาธิคุณที่ทรงแสดงธรรมอันนำไปสู่ความหลุดพ้นแก่สรรพสัตว์อย่างเท่าเทียม

---

## 📖 แก่นธรรมหลัก (Core Teachings)

ภัทราวุธมาณพกราบทูลขอธรรมอันประเสริฐเพื่อตนและหมู่ชน พระผู้มีพระภาคเจ้าได้ทรงแสดงธรรมที่ชี้ตรงไปยังการละตัณหา ดังนี้:

1. **ถอนรากตัณหาในทุกกาล:** ต้องกำจัดความทะยานอยากและความยึดมั่นถือมั่นทั้งในอดีต (เบื้องต่ำ) อนาคต (เบื้องบน) และปัจจุบัน (เบื้องขวาง)
2. **การยึดมั่นคือกับดักของมาร:** สิ่งใดที่เรายึดถือว่าเป็นของเรา สิ่งนั้นคือสายใยที่ "มาร" (กิเลส มัจจุราช และวัฏสงสาร) จะใช้ดึงดูดและติดตามเราไป
3. **การหลุดพ้นจากแดนมาร (มารเธยยะ):** ผู้มีสติที่รู้เท่าทัน ไม่ยึดมั่นสิ่งใดในโลก ย่อมมองเห็นว่าผู้ที่ยังมีความยึดมั่น ล้วนติดอยู่ในบ่วงแห่งความตาย การปล่อยวางคือหนทางเดียวที่จะก้าวล่วงพ้นอาณาจักรของมารได้
